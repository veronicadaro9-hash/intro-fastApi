## Aplicación de ejemplo para crear api con FastApi

#Utilización de libería fastApi

Para poder utilizar la aplicación debe crear un entorno virtual
```
py -m venv entorno
```
Lo activas

```
Para windows .\entorno\Scripts\activate
Para mac o linux source /entorno/bin/activate
```

Una vez creado el entorno y activado debes ejecutar este comando

```
pip install -r requirements.txt
```
